YouTube MP3 Downloader
A simple and easy-to-use script to download audio from YouTube videos and playlists and convert them to MP3.

Requirements
Windows OS
Python 3.x installed
How to use
Install Dependencies:Run install.bat once to install the required Python library (yt-dlp).
Run the Downloader:Double-click run.bat.
Download:Paste the YouTube video or playlist URL into the console window and press Enter.
Features
Downloads best audio quality.
Converts to MP3 automatically.
Supports full playlists.
No complex setup needed.
Files
project.py - The main script.
ffmpeg.exe - Required for audio conversion.
install.bat - Installs dependencies.
run.bat - Launches the script.
